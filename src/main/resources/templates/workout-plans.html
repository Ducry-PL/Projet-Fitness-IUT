API REST disponible

Utilisez l'API REST pour gérer les plans d'entraînement :

  • GET /api/workout-plans - Obtenir tous les plans
  • GET /api/workout-plans/{id} - Obtenir un plan
  • GET /api/workout-plans/user/{userId} - Obtenir par utilisateur
  • POST /api/workout-plans - Créer un plan
  • PUT /api/workout-plans/{id} - Mettre à jour un plan
  • DELETE /api/workout-plans/{id} - Supprimer un plan
